# MultiSub Panel

Панель управления подписками MultiSub для Ubuntu 24.04. Установщик задаёт режим установки, настраивает systemd и Nginx, а для ежедневного управления устанавливает команду `subpanel`.

## Установка

```bash
curl -fsSL https://raw.githubusercontent.com/plaphase/subpanelV2/main/install.sh | sudo bash
```

Bootstrap по умолчанию загружает опубликованную версию `v2.3.0`. В установщике выбери режим:

1. **Новая панель** — пустая база в `/var/lib/multisub-panel`.
2. **Импорт данных** — найди существующий каталог MultiSub или укажи его. Исходные файлы остаются без изменений; панель работает с отдельной копией.
3. **Новая панель в другом каталоге** — задай собственный путь данных.

Установщик отдельно спросит домен панели и домен, который будет стоять в ссылках подписки. Для домена `panel.example.com` и подписок через `cdn.example.com` укажи оба имени и направь DNS-записи на этот сервер. Установщик проксирует оба домена на панель и запросит один Let's Encrypt сертификат на оба имени. Для подписок можно оставить тот же домен, что и для панели.

Для отдельного домена подписок нужен HTTPS. Для установки только по IP доступен временный HTTP режим; он не шифрует логин, пароль и cookie, поэтому не используй его для настоящих учётных данных.

После установки сохрани показанный логин и пароль администратора. Пароль также лежит в root-only файле:

```bash
sudo grep -E '^PANEL_(USERNAME|PASSWORD)=' /etc/multisub-panel/panel.env
```

## Интерфейс и возможности

- Общий навигатор, обзор состояния и быстрые переходы между разделами.
- Избранные профили пользователей и фильтр по ним.
- Диагностика уникальных VPS-источников: HTTP статус и время ответа. За один запуск проверяется до 40 источников; локальные/частные адреса и редиректы блокируются.
- Массовое добавление и удаление источников, сортировка пользователей и группировка событий журнала.
- Работа с корзиной, публичные страницы пользователей и ссылки подписок.

Проверка источников выполняется по нажатию администратора и хранит только код ответа, время проверки и задержку в `/var/lib/multisub-panel/source-health.json`.

## Управление

```bash
sudo subpanel
```

Меню показывает статус службы и Nginx, позволяет менять логин/пароль и выполнить полное удаление. Удаление требует ввести `УДАЛИТЬ ВСЁ`; исходный каталог, использованный для импорта, не удаляется.
Меню также показывает адрес панели из конфигурации. После ошибки в интерактивном пункте оно возвращается к списку действий.

```bash
sudo subpanel --health
sudo subpanel --credentials
sudo systemctl status multisub-panel
sudo journalctl -u multisub-panel -f
```

Новый пароль администратора должен содержать 12–128 символов. Разрешены латинские буквы, цифры и символы `. _ ~ - @`.

## Обновление

Перед обновлением сделай резервную копию `/var/lib/multisub-panel` и `/etc/multisub-panel`. Пакет устанавливается из закреплённой версии, указанную ветку или тег можно заменить переменной `MULTISUB_PANEL_REF`.

## Разработка и проверки

```bash
python -m pip install -r requirements.txt

sudo bash tests/test_installer_paths.sh
sudo bash tests/test_create_config.sh
sudo bash tests/test_install_flow.sh
```

GitHub Actions запускает эти проверки на Ubuntu.
