# MultiSub Panel

Панель управления подписками MultiSub для Ubuntu 24.04. Установщик предлагает режим установки, автоматически настраивает службу systemd и Nginx, а после установки предоставляет команду управления `subpanel`.

## Установка

Запусти на новом сервере одной командой:

```bash
curl -fsSL https://raw.githubusercontent.com/plaphase/subpanelV2/main/install.sh | sudo bash
```

В меню выбери один из вариантов:

1. **Новая панель** — создаёт пустую базу данных в `/var/lib/multisub-panel`.
2. **Импорт существующих данных** — найдёт известные каталоги MultiSub или позволит указать исходный каталог. Источник останется нетронутым, для панели создастся отдельная рабочая копия.
3. **Новая панель в другом каталоге** — задаёт свой каталог данных.

Установщик спросит IP-адрес или домен. Для домена можно настроить HTTPS через Let's Encrypt, указав email. Для IP доступен HTTP режим: браузер будет предупреждать о незашифрованном соединении. Не вводи через публичный HTTP реальные учётные данные и секреты.

После установки установщик покажет адрес, логин и сгенерированный пароль администратора. Сохрани их. Пароль также хранится в `/etc/multisub-panel/panel.env` с правами root-only:

```bash
sudo grep -E '^PANEL_(USERNAME|PASSWORD)=' /etc/multisub-panel/panel.env
```

## Управление

```bash
sudo subpanel
```

Меню позволяет проверить состояние панели и Nginx, изменить логин и пароль администратора, перезапустить службу и удалить панель вместе с её конфигурацией и данными. Удаление требует ввести `УДАЛИТЬ ВСЁ`; исходный каталог, использованный при импорте, не трогается.

Проверка состояния напрямую:

```bash
sudo subpanel --health
```

Смена учётных данных напрямую:

```bash
sudo subpanel --credentials
```

Служба и журнал:

```bash
sudo systemctl status multisub-panel
sudo journalctl -u multisub-panel -f
```

## Обновление

Установщик предназначен для новой установки. Для обновления сначала сделай резервную копию `/var/lib/multisub-panel` и `/etc/multisub-panel`, затем обнови приложение и перезапусти службу. Bootstrap по умолчанию закреплён за опубликованным commit SHA; `MULTISUB_PANEL_REF` позволяет выбрать другой commit, tag или branch.

## Безопасность и эксплуатация

- Все изменения данных сериализуются блокировкой, JSON сохраняется атомарной заменой файла.
- Формы защищены CSRF-токеном; неуспешные входы ограничиваются по IP.
- Панель задаёт защитные HTTP-заголовки и не допускает внешние URL перенаправления после входа.
- Импортируемые адреса подписок проверяются; локальные и частные IP-адреса блокируются.
- В production используй домен и HTTPS. Не выставляй административную панель в открытый HTTP.

## Разработка

Зависимости: Python 3 и пакеты из `requirements.txt`.

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -p 'test_*.py'
```

Shell-проверки установщика запускаются в Ubuntu:

```bash
sudo bash tests/test_installer_paths.sh
sudo bash tests/test_create_config.sh
sudo bash tests/test_install_flow.sh
```
