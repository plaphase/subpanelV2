# История изменений

## 2.3.3 — 12 ноября 2026

### Добавлено и улучшено

- Единая космическая тема для всех разделов панели с монохромными акцентами и адаптацией мобильной навигации.
- Диагностика показывает публичные DNS IP-адреса источников; для доменов за CDN адрес может принадлежать CDN, а не origin-серверу.

### Исправлено

- В стрелочном управлении порядком источников добавлен CSRF-токен, чтобы сервер сохранял новый порядок.
- Удалена ненужная отдельная клиентская страница; для источников используется ссылка подписки.
- Установщик по умолчанию загружает релиз v2.3.3.

## 2.3.2 — 10 ноября 2026

### Добавлено

- Отдельные публичные источники для каждого пользователя: TOP-150 mixed/mobile и VLESS Reality Mobile для белых списков.
- Редактирование URL публичного источника в карточке пользователя.
- Явные подписи подключений в Happ: `[БЕЗОПАСНЫЙ]` для управляемых источников, `[ПУБЛИЧНЫЙ]` для TOP-150 и `[ПУБЛИЧНЫЕ БЕЛЫЕ СПИСКИ]` для Reality Mobile.
- Заголовок Happ с описанием публичных и управляемых источников и интервалом автообновления в один час.
- Перетаскивание источников в массовом управлении и кнопки перемещения вверх/вниз.
- Публичные источники учитываются в обзоре, проверке доступности и массовом удалении.

### Исправлено

- Подписка продолжает обновляться, если один или несколько источников временно недоступны: панель отдаёт доступные подключения и пропускает сбойные.
- При недоступности всех источников возвращается HTTP 503, чтобы клиент не сохранил пустой профиль.
- Журнал обновляется частично без перезагрузки страницы и прыжка прокрутки; фильтры, статусы и группировка результатов по источникам сохраняются.
- Исправлена ошибка `/logs`, из-за которой страница журнала могла отвечать HTTP 500.
